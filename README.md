# jdupes-docker

Unofficial linux docker image for [jdypes](https://codeberg.org/jbruchon/jdupes), cross-platform duplicate file finder.

Get it from GitHub container registry as

`docker pull ghcr.io/davidecavestro/jdupes:latest`


## Usage

You can invoke it with the usual CLI parameters, i.e. the following command
`docker run --rm -it davidecavestro/jdupes --version`
will give you the version.
